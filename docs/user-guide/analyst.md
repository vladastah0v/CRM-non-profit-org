# Аналитик, руководитель программ

Вы работаете с отчётами: цифры по программам и волонтёрам, без карточек людей и ФИО.

## Отчёт по программе для гранта

«Отчёты» → «По программе». Выберите программу и период (по умолчанию — прошлый квартал),
«Показать». Отчёт: уникальные подопечные, факты помощи по типам с количеством и суммой,
разбивка по категориям, часы волонтёров. «Скачать Excel» — для грантодателя.

## Волонтёры

«По волонтёрам»: активные на начало и конец периода, новые, выбывшие, отработанные часы,
неявки. «Воронка»: сколько анкет дошло до каждого статуса и конверсия между шагами.

## Как считаются цифры

Под каждым отчётом — блок «Как считается». Подробно — [docs/reports.md](../reports.md):
по нему удобно сверять отчёт с ручным расчётом.

## Частые вопросы

- **Цифры не совпадают с таблицей.** Проверьте период (обе даты включаются) и программу:
  помощь без программы попадает только в «Без программы» и «Все программы».
- **Нужны ФИО волонтёров.** Таблица по людям — у координатора и администратора.
- **Каждая выгрузка видна администратору** в журнале аудита — это требование закона.
