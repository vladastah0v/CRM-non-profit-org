# Отчёты: как считается каждый показатель

Для сверки отчётов с ручным расчётом фонда (результат этапа 8 ТЗ). Отчёты — меню
«Отчёты»; любой отчёт выгружается в Excel кнопкой «Скачать Excel», каждая выгрузка
записывается в журнал аудита.

Общие правила:

- Период включает обе даты. По умолчанию — прошлый календарный квартал.
- Даты и время — по часовому поясу фонда.
- Записи в архиве (ошибочные, дубли) не учитываются. Обезличенные люди учитываются:
  их факты помощи, часы и статусы остаются в статистике.

## Отчёт по программе (ФТ-О-01)

Кто видит: администратор и аналитик — по всем подопечным, куратор — по своим.

| Показатель | Как считается |
|---|---|
| Факты помощи | Записи «Оказанная помощь» с датой оказания в периоде и выбранной программой. «Все программы» — без фильтра, «Без программы» — где программа не указана |
| Уникальные подопечные | Сколько разных подопечных получили хотя бы одну такую помощь (человек считается один раз) |
| По типам помощи | Число фактов, сумма количества (отдельно по каждой единице измерения) и сумма в рублях |
| По категориям | Уникальные подопечные по категориям; без категории — отдельной строкой |
| Часы волонтёров | Только при отчёте по всем подопечным: отметки «Пришёл» на сменах программы и визитах с этой программой, начавшихся в периоде, плюс часы, внесённые вручную с этой программой и датой в периоде |

## Отчёт по волонтёрам (ФТ-О-02)

Кто видит: администратор, координатор, аналитик. Таблица по людям (ФИО) — только
администратору и координатору; аналитику — итоги без ФИО.

| Показатель | Как считается |
|---|---|
| Активных на начало / на конец | Статус «Активен» на начало первого дня / на конец последнего дня периода — по журналу смены статусов. Обезличенный волонтёр после даты обезличивания не считается |
| Новые | Впервые получили статус «Активен» в периоде (поле «Дата начала») |
| Новых анкет | Карточки, созданные в периоде (вручную, с сайта, импортом) |
| Выбыли | Переведены в «Выбыл» в периоде |
| Работали в периоде | Были отмечены «Пришёл» на смене или визите, начавшихся в периоде, или им внесены часы вручную с датой в периоде |
| Проведено смен | Неотменённые смены, начавшиеся в периоде |
| Неявки и доля неявок | Отметки «Не пришёл» на сменах и визитах периода; доля — от всех отметок «Пришёл» и «Не пришёл» |
| Часы | На сменах и визитах — по отметкам «Пришёл» (время начала в периоде); вручную — по дате записи |

## Воронка волонтёров (ФТ-О-03)

Кто видит: администратор, координатор, аналитик.

- Когорта — анкеты (карточки), созданные в периоде.
- Шаг «Собеседование», «Обучение», «Активен» пройден, если волонтёр хоть раз был
  переведён в этот статус — даже если потом выбыл.
- Конверсия «от предыдущего шага» и «от анкет» — в процентах, с одним знаком.
- «Сейчас по статусам» — все действующие карточки на момент отчёта, без учёта периода.

## Выгрузка списков (ФТ-О-04)

Кнопка «Excel» в списках волонтёров, подопечных, заявок и смен выгружает список с
текущими фильтрами и в пределах прав. Роли с ограниченным доступом получают только поля
набора «О». Защищённые данные подопечного (здоровье, документы) и тексты заявок не
выгружаются никогда. Не больше 10 000 строк за раз — при большем числе уточните фильтры.
