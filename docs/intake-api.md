# Приём анкет с сайта фонда: волонтёры и подопечные

Для разработчика сайта фонда (Tilda, WordPress, своя форма). Требования — п. 7.1 ТЗ.

## Запрос

```
POST https://<домен CRM>/api/v1/intake/volunteer/
Content-Type: application/json
X-Timestamp: 1791295200
X-Signature: sha256=3f1c…e9a0
```

Тело — JSON в UTF-8, не больше 64 КБ:

| Поле | Обязательно | Формат |
|---|---|---|
| `last_name`, `first_name` | да | строка до 150 символов |
| `middle_name` | нет | строка |
| `birth_date` | да | `ГГГГ-ММ-ДД` или `ДД.ММ.ГГГГ` |
| `phone` | да | любой формат российского номера: `+7 916 123-45-67`, `8 (916) 1234567` |
| `email` | нет | email |
| `telegram` | нет | имя пользователя, можно с `@` |
| `city`, `district` | нет | район сопоставляется со справочником CRM по названию |
| `skills` | нет | список названий навыков; неизвестные пропускаются |
| `availability` | нет | список `{"weekday": 0–6 (0 — понедельник), "time_from": "18:00", "time_to": "21:00"}` |
| `consent` | да | `true` — отметка о согласии на обработку данных со ссылкой на политику |
| `guardian_name`, `guardian_phone` | если нет 18 лет | ФИО и телефон законного представителя |
| `guardian_relation`, `guardian_email` | нет | «мать», «отец», «опекун»… |
| `guardian_consent` | если нет 18 лет | `true` — согласие дал законный представитель |

Пример:

```json
{
  "last_name": "Волкова",
  "first_name": "Ирина",
  "birth_date": "1990-04-20",
  "phone": "+7 926 000-11-22",
  "email": "irina@example.org",
  "district": "Центральный",
  "skills": ["Вождение"],
  "availability": [{"weekday": 5, "time_from": "10:00", "time_to": "15:00"}],
  "consent": true
}
```

## Обращение подопечного

```
POST https://<домен CRM>/api/v1/intake/beneficiary/
```

Заголовки и подпись — те же, что для анкеты волонтёра (раздел «Подпись» ниже).

| Поле | Обязательно | Формат |
|---|---|---|
| `last_name`, `first_name` | да | строка до 150 символов |
| `middle_name` | нет | строка |
| `birth_date` | да | `ГГГГ-ММ-ДД` или `ДД.ММ.ГГГГ` |
| `phone` | да | любой формат российского номера |
| `address` | нет | строка до 500 символов |
| `category` | нет | категория подопечных — сопоставляется со справочником CRM по названию |
| `need` | нет | какая помощь нужна, до 2000 символов. **Не спрашивайте в форме о здоровье и документах**: для этих данных нужно отдельное согласие |
| `consent` | да | `true` — отметка о согласии на обработку данных |
| `representative_name`, `representative_phone` | если нет 18 лет | ФИО и телефон законного представителя |
| `representative_relation` | нет | «мать», «опекун»… |
| `representative_consent` | если нет 18 лет | `true` — согласие дал законный представитель |

В CRM появляется карточка «Новый» без куратора; администраторы получают уведомление и
назначают куратора. Текст `need` сохраняется в карточке как сообщение «Обращение с сайта».
При совпадении с существующей карточкой обращение всё равно принимается — с пометкой
«возможный дубль», решение принимает администратор.

## Подпись

Секрет выдаёт администратор CRM (переменная `INTAKE_HMAC_SECRET` на сервере CRM).
Секрет хранится только на сервере сайта — **никогда не в JavaScript страницы**.
Поэтому форма отправляет данные на сервер сайта, а уже он — в CRM.

```
X-Timestamp = текущее unix-время в секундах
X-Signature = "sha256=" + hex( HMAC-SHA256( секрет, X-Timestamp + "." + тело запроса ) )
```

Подписываются **ровно те байты**, что уходят в теле запроса. Часы сервера сайта
должны идти точно: запрос старше 5 минут отклоняется. Одну и ту же подпись можно
использовать один раз — повтор получит ответ 409.

PHP:

```php
$body = json_encode($data, JSON_UNESCAPED_UNICODE);
$ts = (string) time();
$signature = 'sha256=' . hash_hmac('sha256', $ts . '.' . $body, getenv('CRM_INTAKE_SECRET'));
// заголовки: Content-Type: application/json, X-Timestamp: $ts, X-Signature: $signature
```

Python:

```python
body = json.dumps(data, ensure_ascii=False).encode()
ts = str(int(time.time()))
signature = (
    "sha256=" + hmac.new(secret.encode(), f"{ts}.".encode() + body, hashlib.sha256).hexdigest()
)
requests.post(
    url,
    data=body,
    headers={"Content-Type": "application/json", "X-Timestamp": ts, "X-Signature": signature},
    timeout=10,
)
```

## Ответы

| Код | Что значит | Что делать сайту |
|---|---|---|
| 201 | Анкета принята | Показать «Спасибо, координатор свяжется с вами» |
| 400 | Ошибки в данных: `{"errors": {"phone": ["…"]}}` | Показать ошибки в форме. Тот же запрос можно отправить повторно |
| 403 | Нет подписи, подпись неверна или устарела | Проверить секрет и часы сервера |
| 409 | Этот запрос уже был принят | Ничего: анкета уже в CRM |
| 413 / 415 | Слишком большое тело / не JSON | Исправить интеграцию |
| 429 | Больше 10 запросов в минуту с одного IP | Повторить позже |
| 503 | Приём анкет на стороне CRM не настроен | Сообщить администратору CRM |

Ответ не сообщает, есть ли человек в базе: совпадения с существующими карточками
CRM помечает как «возможный дубль», а решение принимает координатор.

Защиту от ботов (капчу) ставит сайт: ограничение в 10 запросов в минуту действует на IP
сервера сайта, то есть на все анкеты сразу.
